ADLSCA: teaching a neural network to remember what it has already learned

Ahmed H. Rashed

Why I started

I started this project after watching a TikTok about how the human brain learns skills, and how neurons connect to form groups of skills. I wondered: why can't AI do the same? Why can't it remember skills by how common they are, and let useless or false skills fade, the way people forget?

What I found

I expected it to work right away and to be very human-like. It wasn't that simple. Computers don't learn the way brains do; they are matrices that get multiplied over and over. So I researched encoders and how tokens are made, and an encoder looked like a simpler version of what I had imagined. That made me wonder whether an encoder could become the core of the system.

The version that works best, v4.9.3, is a plain memory bank. On my one MNIST test it cut error to 0.638 of a plain network's, so it "works" on that test, and only that test. What surprised me most is also what disappointed me most: my own equations did not earn their place, and the simple design beat them. In my tests, the simplest design worked best.

What comes next

The next stage, version 5, is meant to use a learned encoder to build the memory keys, and later to connect the memory to a language model. That is planned and has not been tested. So far, package v5.0 only rebuilds the same memory bank as a single PyTorch module.

Please read this first.

  • All results on this site come from one MNIST test: a stream of handwritten digits that switches between groups of digits. They show the system works on this test, not in general.
  • Connecting the memory to a language model is planned and untested.
  • I do not claim a new invention. The design is close to existing work. What I claim is that I designed, built and tested this system, and I report what I found, including what failed.

Featured report

ADLSCA v4.9.3 Report

v4.9.3 is the final memory design: a keyed memory bank. On 16 fresh held-out seeds (8000-8015), scored once with nothing changed afterwards, it cut overall error to 0.638 times a plain network without memory, and it beat that baseline on all 16 seeds.

    The code

    A note on how the code was written. An AI assistant helped write the code for this project. I designed the experiments, chose what to test, ran every experiment myself, and decided which versions to keep and which to drop.

    The final system is adapter --bank 1 in package v4.9.3. The held-out test was run with run_final_heldout.bat, and its commands were frozen in configs/final_heldout_v493.json before any result was seen.

    Package v5.0 rebuilds the same bank as one PyTorch module and reproduces the v4.9.3 results exactly.
